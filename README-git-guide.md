# 🚀 คู่มือการใช้งาน Git และ GitHub (ฉบับสมบูรณ์)

คู่มือนี้รวบรวมขั้นตอนการอัพโหลดโค้ดขึ้น GitHub ตั้งแต่เริ่มต้น พร้อมวิธีจัดการ เพิ่ม/ลบ ไฟล์หรือโฟลเดอร์แบบเจาะจงอย่างละเอียด

---

## 📌 1. วิธีอัพโค้ดขึ้น GitHub ครั้งแรก (First Commit)

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าไปที่ [GitHub](https://github.com/) แล้วกดปุ่ม **New** (หรือเครื่องหมาย `+` มุมขวาบน)
2. ตั้งชื่อโปรเจกต์ในช่อง **Repository name**
3. เลือก **Public** หรือ **Private** ตามต้องการ
4. **ห้าม** ติ๊กเลือก *Add a README file*, *.gitignore* หรือ *License* (ปล่อยว่างไว้)
5. กดปุ่ม **Create repository** แล้วคัดลอก URL เอาไว้ (เช่น `https://github.com/username/repo-name.git`)

### ขั้นตอนที่ 2: รันคำสั่ง Git ใน Terminal
เปิด Terminal หรือ Git Bash ในโฟลเดอร์โปรเจกต์ของคุณ แล้วพิมพ์คำสั่งตามลำดับดังนี้:

```bash
# 1. เริ่มต้นใช้งาน Git ในโปรเจกต์
git init

# 2. ตั้งค่าชื่อและอีเมล (ทำแค่ครั้งแรกครั้งเดียวบนเครื่อง)
git config --global user.name "ชื่อโปรไฟล์ภาษาอังกฤษ"
git config --global user.email "อีเมลที่ใช้สมัคร GitHub"

# 3. เลือกไฟล์ทั้งหมดเตรียมอัปโหลด
git add .

# 4. บันทึกสถานะเวอร์ชันแรก
git commit -m "First commit"

# 5. เปลี่ยนชื่อ Branch หลักให้เป็น main
git branch -M main

# 6. เชื่อมโปรเจกต์ในเครื่องกับ GitHub (แทนที่ URL ด้วยลิงก์ของคุณ)
git remote add origin https://github.com/username/repo-name.git

# 7. อัปโหลดโค้ดขึ้น GitHub
git push -u origin main
```

## 📌 2. วิธีอัปเดตโค้ดในครั้งต่อไป
เมื่อมีการแก้ไขโค้ดเพิ่มในอนาคต และต้องการอัพขึ้น GitHub ให้ใช้เพียง 3 คำสั่งสั้นๆ ดังนี้:
```bash
git add .
git commit -m "อธิบายสิ่งแก้ไขหรือฟีเจอร์ที่เพิ่มเข้าไป"
git push
```

## 📌 3. วิธีจัดการ เพิ่ม/ลบ เฉพาะไฟล์หรือโฟลเดอร์

### 📂 การอัพโหลด "เฉพาะบางโฟลเดอร์" หรือ "บางไฟล์"
หากคุณไม่ต้องการอัพเดตทุกไฟล์ (ไม่ใช้ `git add .`) คุณสามารถเจาะจงเลือกเฉพาะบางสิ่งได้:

*   **เลือกอัพเฉพาะบางโฟลเดอร์:**
    ```bash
    git add ชื่อโฟลเดอร์/
    # ตัวอย่าง: git add public/
    ```
*   **เลือกอัพเฉพาะบางไฟล์:**
    ```bash
    git add ชื่อไฟล์.นามสกุล
    # ตัวอย่าง: git add server.js
    ```
*   **จากนั้นทำการบันทึกและส่งตามปกติ:**
    ```bash
    git commit -m "Update specific files"
    git push
    ```

### 🗑️ การลบไฟล์/โฟลเดอร์ออกจาก GitHub (แต่ไม่ลบในเครื่องคอม)
ในกรณีที่เผลออัพโหลดไฟล์ขนาดใหญ่ ไฟล์ความลับ หรือโฟลเดอร์สำรองขึ้นไป แล้วต้องการลบออกเฉพาะบนหน้าเว็บ GitHub โดยที่**ไฟล์จริงในเครื่องยังอยู่ครบ** ให้ทำดังนี้:

*   **กรณีต้องการลบ "ทั้งโฟลเดอร์":**
    ```bash
    git rm -r --cached ชื่อโฟลเดอร์
    # ตัวอย่าง: git rm -r --cached photobooth_backups
    ```
*   **กรณีต้องการลบ "เฉพาะบางไฟล์":**
    ```bash
    git rm --cached ชื่อไฟล์.นามสกุล
    # ตัวอย่าง: git rm --cached cloudflared.exe
    ```
*   **หลังจากนั้นต้อง Commit และ Push เพื่ออัปเดตหน้าเว็บ GitHub:**
    ```bash
    git commit -m "Remove untracked assets from remote"
    git push
    ```

## 📌 4. วิธีใช้ `.gitignore` ป้องกันไม่ให้ไฟล์กลับขึ้นไปอีก
หลังจากที่ลบไฟล์/โฟลเดอร์ออกจาก Git ตามข้อก่อนหน้าแล้ว เพื่อป้องกันไม่ให้คำสั่ง `git add .` หยิบมันขึ้นไปบน GitHub อีกในอนาคต ให้สร้างหรือเปิดไฟล์ชื่อ `.gitignore` ไว้ที่โฟลเดอร์นอกสุดของโปรเจกต์ แล้วเพิ่มชื่อสิ่งที่ไม่ต้องการลงไป:

```text
# ตัวอย่างการเขียนในไฟล์ .gitignore

node_modules/
photobooth_backups/
cloudflared.exe
.env
*.log
```
